# src/core/ui

সব ব্যবসা ও module-এর জন্য এক UI উপাদান। কোনো ব্যবসার নাম, নিয়ম বা ডেটা আনা নেই।

- কাঠামো: `AppShell`, `Sidebar` (ছোট করা যায়), `Topbar`, `MobileDrawer`, `NavLinks`।
- উপাদান: `Button`, `Card` (glass), `Modal`, `PageHeader`, `EmptyState`, `Skeleton`, `Pagination` (১০ সারি)।
- সুইচ: `ThemeToggle`, `LocaleSwitcher`।

সব লেখা next-intl থেকে, সব রঙ টোকেন ক্লাস থেকে। সব উপাদান একসাথে দেখতে ডেভে `/dev/ui` খোলো।
